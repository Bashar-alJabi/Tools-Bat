# 🛠️ Image Convert

> تحويل صيغة الصور

## 🎯 What does Image Convert do?

تحويل صيغة الصور. هذا الدليل خاص بملف `Image Convert.bat` الموجود في هذا المجلد، ويوضح التشغيل الحالي. المراجع الأصلية المفصلة محفوظة بجانبه، ولم تُحذف القوائم الأصلية العاملة.

## 📦 المتطلبات والصيغ

- Windows 10/11 و Windows PowerShell 5.1 المدمج، دون Administrator.
- البرنامج المطلوب: **ImageMagick 7**.
- الصيغ: JPG/JPEG/PNG/WebP/BMP/TIF/TIFF/GIF/AVIF.
- تبدأ أولوية الاكتشاف من `../../_bin` ثم النسخة المثبتة المتوافقة. استخدم [START_HERE](../../START_HERE.md) عند غيابها؛ لا تنزّل الأداة برنامجًا دون موافقة.
- يجب نقل شجرة المشروع مع `_shared`؛ BAT وحده لا يحمل ملفات المعالجة المشتركة.

## ⭐ أفضل طريقة للاستخدام اليومي

1. ضع الملفات داخل `Input` بجانب BAT.
2. افتح `Image Convert.bat`، ثم اختر من القائمة الأصلية.
3. أكّد العملية عندما يُطلب ذلك.
4. راجع ملخص SUCCESS/FAILED/SKIPPED؛ النتائج في `Output`.
5. افحص المحتوى بصريًا/سمعيًا أو افتح التقرير قبل استخدامه.

## ⚙️ خيارات القائمة والإعدادات

الإعداد التلقائي عند استخدام `--defaults`: **JPG جودة 85، خلفية بيضاء للشفافية**.

الصيغ JPG و PNG و WebP و TIFF و BMP و GIF و AVIF. الجودة 1–100 للصيغ المناسبة. JPG يزيل الشفافية على خلفية بيضاء. الإطارات المتعددة تتطلب GIF/WebP/TIFF في الناتج.

القائمة الظاهرة في BAT (النسب المئوية مكتوبة بصيغة Batch `%%`):

```text
Select output format:
[1] JPG
[2] PNG
[3] WebP
[4] TIFF
[5] BMP
[6] GIF
[7] AVIF
[Q] Quit
```

## 📁 Input / Output

```text
Image Convert.bat
Image Convert.md
Input/
Output/
```

لكل أداة مجلدا Input و Output داخل مجلدها. لا تقرأ من مجلد العمل الحالي عند استدعائها خارجيًا.

ملفات `.gitkeep` للتنظيم ولا تُعالج. الروابط و Junctions تُتجاوز، ولا يجري تتبعها. شجرة Input كاملة فقط لأدوات الجرد والبصمات والتكرارات والنسخ الاحتياطي؛ بقية المعالجة للملفات المباشرة.

## 📚 أمثلة عملية

```bat
"Image Convert.bat"
"Image Convert.bat" --help
"Image Convert.bat" --check
set "TB_NO_PAUSE=1"
"Image Convert.bat" --defaults
```

مثال: ضع photo.jpg في Input، ثم شغّل الإعداد الافتراضي. اسم الناتج وصيغته موضحان في فقرة الخيارات. كل نتيجة جديدة تحفظ داخل Output الخاص بالأداة.

عند الاستدعاء من مجلد آخر، استخدم المسار الكامل المحاط بعلامتي اقتباس. لا تستخدم CALL إضافيًا مع أسماء مسارات تحوي `%`؛ وأوقف Delayed Expansion في CMD الأب عند وجود `!`.

## 🧠 كيف تعمل الأداة؟

BAT يحتفظ بالقائمة واختياراتها، ويستدعي المعالجة الآمنة في ../../_shared/ToolRunner.ps1. الملفات Check.ps1 و Validate.ps1 لفحص الاعتماد والمدخلات فقط؛ لا توجد مكتبات PowerShell خارجية.

تُمرر أسماء الملفات إلى برامج المعالجة مباشرة دون shell، مع أسماء عمل بسيطة عندما تفسر برامج الصور رموز أسماء الملفات. يُجهز الناتج في مجلد عمل خاص، ثم يُنشر بعد نجاح العملية وفحص الملف الناتج.

## 🚨 المشاكل والأخطاء

| الحالة | التصرف |
|---|---|
| اعتماد مفقود/غير متوافق | شغّل START_HERE أو جهّز توزيعة محلية كاملة |
| لا مدخلات مدعومة | راجع Input والصيغ؛ الخروج 0 يعني عدم وجود عمل |
| SKIPPED | الناتج موجود؛ لا يُستبدل ولا يُحذف تلقائيًا |
| FAILED/Invalid | راجع الملف والإعدادات ورسالة البرنامج؛ الأصل محفوظ |
| مساحة أو صلاحية غير كافية | استخدم مجلدًا قابلًا للكتابة ومساحة للملفات الوسيطة |
| المسار أطول من 240 محرفًا | انقل المشروع/الملف إلى مسار أقصر |

كود الخروج 0 للنجاح/عدم وجود عمل/التخطي، 1 لفشل ملف أو عدم تطابق البصمات، 2 لإعداد أو تشغيل غير صالح، و 3 عادة لاعتماد مفقود في BAT الأصلي. أدوات الدفعة التسع البسيطة قد ترجع 2 للاعتماد المفقود.

## ⚠️ القيود والملاحظات

لا تُستبدل نتيجة لها الاسم نفسه؛ ملفان لهما الاسم الأساسي نفسه ويخرجان إلى الصيغة نفسها قد يتعارضان، فتُتخطى النتيجة الثانية. لا تعني رسالة نجاح أن الجودة مناسبة لكل غرض. عمليات الصور والصوت و PDF قد تعيد الترميز أو تغير metadata؛ راجع الناتج واحتفظ بالأصل.

البرامج المكتشفة في النظام لا تنتقل تلقائيًا إلى جهاز آخر. استخدم نسخة توزيع بها توزيعات محلية كاملة ومرخصة عند الحاجة للعمل دون إنترنت.

## 🛡️ الأصول والنتائج

لا حذف أو تعديل للملف الأصلي، ولا تغيير PATH العام أو Registry. يُحذف مجلد العمل المؤقت الخاص بهذه العملية فقط. مدير الاعتمادات لا يعمل تلقائيًا من هذه الأداة.
