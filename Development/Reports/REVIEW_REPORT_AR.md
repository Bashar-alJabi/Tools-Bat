# تقرير مراجعة وتطوير tOOls Bat

تاريخ العمل: **2026-10-17**. جرى التطوير والاختبار داخل مجلد المشروع نفسه، مع حفظ الأصل قبل أي تعديل. لا توجد تنزيلات برامج أو تثبيتات أو تغييرات PATH عامة أو Registry أو طلبات Administrator أثناء التطوير.

## الحالة الأصلية وما تمت مراجعته

المشروع قبل التعديل يضم **21 ملف BAT و15 ملف Markdown، بمجموع 36 ملفًا**. لا توجد ملفات CMD، ولا نسخ برامج محلية، ولا ملفات BAT مبتورة أو TODO يحدد أداة غير مكتملة. مجلدا AUD وUTI فارغان؛ مجلدات Input وOutput وWatermark الأصلية خالية من بيانات المستخدم.

قُرئ محتوى الأدوات الأصلية ومنطق قوائمها ومعالجتها، لا أسماؤها فقط. النمط الأصلي هو BAT مستقل لكل وظيفة، عنوان وفواصل نصية إنجليزية، مجلد Input وOutput بجانب السكربت، إعدادات بقائمة، وتخطي النتائج الموجودة في معظم الأدوات. الاعتمادات الفعلية كانت FFmpeg وImageMagick وGhostscript؛ أضيف استعمال FFprobe فقط لأداة Media Info الجديدة.

بقيت أسماء الملفات والأقسام والقوائم والخيارات الأساسية. ملفات BAT القديمة تحتفظ بقوائمها وإعداداتها؛ انتقلت حلقات معالجة الملفات وتنفيذ البرامج ونشر النتائج إلى `System/Shared/ToolRunner.ps1` و`Core.ps1` لتجنب تفسير أسماء الملفات على أنها أوامر cmd أو صيغ ImageMagick. لم يُحذف أي ملف أصلي.

الأصل محفوظ داخل `Development/Original/original.zip`، وبصماته قبل التعديل داخل `Development/Original/manifest.json`. تحقق الاختبار من تطابق **كل الملفات الأصلية الستة والثلاثين** مع هذه البصمات. يوجد سجل التحويل التطويري `Development/Original/review-transform.ps1` الذي يرفض العمل على ملفات سبق تعديلها. لم يكن المجلد مستودع Git عند البدء؛ استُخدمت نسخة أصلية مستقلة للاسترجاع.

بنية **المجلدات الأصلية الـ51**، بما فيها Input/Output وAUD وUTI الفارغة، مسجلة في `Development/Original/directories.json`. سكربت `Development/Original/Restore-ToFolder.ps1` يسترجع الملفات والمجلدات إلى وجهة جديدة، ويتحقق من البصمات ويرفض الكتابة فوق وجهة موجودة. اختُبر الاسترجاع فعليًا في مجلد تجريبي.

## المشكلات الفعلية والإصلاحات

| معالجة wildcard غير مطابق كأنه ملف حقيقي | حصر المعالجة بالملفات الحقيقية المدعومة، مع التعامل الآمن مع Input الخالي أو الملفات غير المدعومة |
| الاعتماد على PATH وحده وعدم فحص النسخة | اكتشاف مشترك: `System/Bin` أولًا، ثم النظام، مع تشغيل واختبار إصدار وقدرات أساسية |

الفيديو الصامت مدعوم في السرعة وFPS والدقة والضغط. العمليات التي تحتاج صوتًا ترفض ملفًا بلا مسار صوت برسالة فشل واضحة. دمج/استبدال الصوت يتطلبان فيديو واحدًا وصوتًا واحدًا، حتى لا تختار الأداة ملفًا عشوائيًا عند وجود عدة ملفات.

## نواقص المنظومة التي اكتملت

لم توجد أداة BAT جزئية مستقلة يمكن نسبتها إلى قائمة قديمة محددة. اكتملت النواقص المشتركة: مدخل تجهيز موحد، واكتشاف الاعتمادات والتحقق منها، وتنزيلات بموافقة وحزم مثبتة ببصمات، ومعالجة Unicode والأخطاء والنتائج الجزئية، وتعليمات نقل واستخدام، واختبارات قابلة للإعادة.

ملفات البنية المضافة:

- `START_HERE.bat` و`System/Shared/Setup.ps1`: فحص وتجهيز وإعادة محاولة.
- `Core.ps1` و`Check.ps1` و`Validate.ps1`: تشغيل البرامج، الاكتشاف، المسارات والتحقق.
- `ToolRunner.ps1` و`NewTool.ps1`: معالجة الأدوات الأصلية ومشغلات الإضافات.
- `Archives.ps1` و`Download.ps1`: ZIP والتحقق والتنزيل والنشر المحلي.
- `tools.json` و`packages.json`: سجل الأدوات واعتماداتها والحزم والإصدارات والبصمات.
- `README.md` و`System/Docs/DEPENDENCIES.md` و`Development/Reports/PRIORITIES.md` وهذا التقرير، واختبارات `tests`.

## الأدوات الجديدة المنفذة

1. Audio Converter: تحويل ملفات الصوت نفسها إلى خمس صيغ؛ لا يكرر أداة Convert Audio القديمة التي تحول الصوت داخل فيديو.
2. Video Thumbnail: استخراج الإطار الأول إلى PNG.
3. Merge PDF: دمج حسب اسم الملف إلى نسخة PDF جديدة.
4. Media Info: تقارير JSON للترميزات والمسارات والمدة والبيانات الوصفية.
5. File Hashes: manifest SHA-256 والتحقق من الفقد والتغيير والملفات الإضافية.
6. Duplicate Finder: تقرير المحتوى المكرر بعد مطابقة الحجم والبصمة دون حذف.
7. File Inventory: جرد CSV بمسارات نسبية وأحجام وتواريخ UTC.
8. ZIP Backup: ضغط محتويات شجرة Input، مع الملفات المخفية والمجلدات الفارغة.
9. ZIP Extract: استخراج مستقل لكل أرشيف مع رفض Zip Slip والروابط والأسماء غير الآمنة والتكرار المتعارض.

جميع الإضافات قابلة للنقل، وتعمل دون Administrator، وتحفظ الملفات الأصلية، ولا تضيف برنامجًا خارجيًا جديدًا خارج الاعتمادات المتوفرة أصلًا وFFprobe المرافق لـFFmpeg.

لم تُنفذ أدوات حذف التكرارات آليًا أو تعديل Registry/تنظيف النظام، ولا OCR أو AI أو تنزيل نماذج جديدة. أسباب الاختيار والأولوية موجودة في `Development/Reports/PRIORITIES.md`: الفائدة، وضوح الوظيفة، انخفاض المخاطر، وتجنب إدخال اعتماد ثقيل غير مطلوب. إشارات AI وFrame Interpolation في المراجع القديمة مقارنات تقنية؛ لم يُفترض أنها أدوات مخططة ذات مواصفات مفقودة.

## الاعتمادات وSTART_HERE

التفاصيل لكل أداة والمصادر والتراخيص في `README.md` و`System/Docs/DEPENDENCIES.md`. FFmpeg لأدوات الفيديو والصوت؛ ImageMagick لتسع أدوات الصور؛ Ghostscript لأداتي PDF؛ FFprobe لأداة معلومات الوسائط. أدوات الملفات وZIP لا تحتاج تنزيل برنامج خارجي.

عند تشغيل START_HERE:

1. يكتشف موضع المشروع وWindows والمعمارية وPowerShell، ثم يعرض النسخ المحلية والمثبتة والأدوات المستخدمة لها.
2. يستخدم النسخة المحلية المتوافقة أولًا ثم النظام. لا يخزن مسارات هذا الجهاز كإعدادات ثابتة.
3. إذا غاب اعتماد، يعرض الاسم والإصدار والحجم التقريبي ورابط الحزمة ومصدرها ورخصتها، ويطلب موافقة مستقلة. الإجابة الفارغة رفض.
4. يعتمد FFmpeg 9.0.2 وImageMagick 7.1.2-34 وGhostscript 10.08.0 بروابط إصدار ثابت وبصمات SHA-256 ثابتة من بيانات الناشرين، دون روابط latest أو تنفيذ سكربت بعيد.
5. ينزل إلى مساحة مؤقتة، ويتحقق من البصمة، ثم يستخرج ZIP أو 7z، ويفحص EXE والإصدار، ويحفظ التوزيعة الكاملة داخل `System/Bin` بما فيها التراخيص.
6. يعيد الفحص ويعرض نجاحًا أو تجهيزًا جزئيًا مع خيار إعادة المحاولة. يحفظ التجهيز السابق ولا يستبدل مجلدًا مكسورًا أو أرشيفًا مخبأ تالفًا دون تدخل المستخدم.

Ghostscript حالة موثقة: المتاح الرسمي الذي تحقق منه الفحص مثبت Windows، فيُنزّل ويُفحص فقط ولا يُشغّل. يجهزه المستخدم يدويًا أو يضع توزيعًا محليًا كاملًا مرخصًا داخل `System/Bin/ghostscript`. لا يتجاوز النظام متطلبات الموافقة على التثبيت أو الرخصة. التنزيل التلقائي معد لـx64؛ x86 وARM64 يحتاجان توزيعًا يدويًا متوافقًا.

## الاختبارات العملية وحدودها

أُجريت الاختبارات على **Windows فعلي x64، إصدار النظام 10.0.26300.0، وWindows PowerShell 5.1.26100.9549**. استُخدمت النسخ الموجودة من FFmpeg/FFprobe 9.0.1 وImageMagick 7.1.2-30 وGhostscript 10.07.1 دون تثبيت أو تنزيل تحديث.

تشمل الاختبارات:

- تشغيل كل BAT فعليًا من مجلد عمل مختلف، ومعالجة جديدة في التشغيل الأول، وتحقق SHA-256 من بقاء المدخلات، ثم إعادة التشغيل للتحقق من بقاء النتائج.
- نسخة مشروع في مسار تجريبي به العربية والمسافات و`! % & ^ () []`، مع أسماء ملفات عربية ومحارف خاصة.
- اختبار غياب الاعتمادات لكل أداة، وتشغيل START_HERE مرارًا، ورفض كل عروض التنزيل دون بدء تحميل.
- تشغيل اختيارات قوائم حقيقية من cmd، إلى جانب فحص خيارات المعالجة؛ جرى عزل نتائج أدوات الصوت المشتركة حتى تنفذ كل وظيفة فعليًا.
- صيغ الصور السبع، وصيغ الصوت الخمس، ومستويات PDF الخمسة، وأبعاد القص والتكبير والتصغير، والشفافية، وعلامة بشفافية 100% وتسعة مواضع.
- فيديو صامت، ومعدل 60 FPS، وتغيير مدة السرعة، وHEVC، وإزالة مسار الصوت فعليًا، وMP3، وإزالة تعليق metadata، وعد صفحات PDF بعد الدمج.
- ملفات تالفة، ومدخلات رقمية غير صحيحة، وتكرار الاسم الأساسي، وغموض ملفات الاستبدال، وملفات غير مدعومة، ومجلد Input مفقود ومسار أطول من الحد المدعوم.
- ZIP بمسارات خروج أو ADS أو أسماء أجهزة Windows أو أسماء متعارضة أو روابط رمزية؛ والتحقق من شجرة مخفية ومجلد فارغ.
- مسار إخراج محجوز بملف قائم، وفحص رفض مساحة غير ممكنة دون ملء القرص أو تغيير ACL.
- فشل شبكة/HTTP فعلي لطلب metadata، وفشل اتصال محاكى وتنزيل جزئي وتالف، والتحقق من بقاء التجهيز السابق.
- مسار تجهيز ZIP و7z ناجح بملفات اختبار محلية وبصمات صحيحة وEXE اختباري صغير بُني محليًا، مع التحقق من الإصدار وحفظ الترخيص وإعادة استعمال cache؛ لم تُنزّل برامج لهذا الاختبار.
- نسخ توزيعات البرامج الموجودة كاملة إلى مشروع مؤقت وتشغيل الصور والعلامة والفيديو وPDF وFFprobe وSTART_HERE منها، مع تعطيل اكتشاف النظام وحصر PATH بمجلدات Windows. حُذفت هذه النسخ المؤقتة فقط بعد الاختبار؛ `System/Bin` الفعلي بقي خاليًا.
- فحص Parsing لكل PS1، وتطابق الكتالوج والحزم، وسلامة أرشيف الأصل، وعزل بيانات الاختبار عن Input/Output الفعليين.

لم تُنفذ اختبارات تنزيل الأرشيفات الأصلية من الإنترنت أو تشغيل مثبت Ghostscript. لم تُختبر نسخة Windows 10 مستقلة أو x86/ARM64 أو USB فعلي أو مشاركة UNC، ولا ملفات فعلية أكبر من 2 GB أو ملء قرص أو تغيير ACL أو جميع أنواع GPU وتعريفاتها. فحص مساحة التخزين ومحاكاة الأخطاء لا يعادلان هذه التجارب. اختبارات metadata تثبت حذف التعليق المختبر، ولا تدّعي إثبات إزالة كل نوع من بيانات GPS/EXIF في كل صيغة.

## القيود الباقية وطريقة النقل

حد المسار المحافظ 240 محرفًا؛ ZIP غير المشفر بحد استخراج 20 GB و100000 عنصر. ملفات GIF/TIFF/WebP متعددة الإطارات تُحفظ عندما يدعم الناتج ذلك؛ النتائج الثابتة والعلامة المائية متعددة الإطارات تُرفض برسالة واضحة. بعض نسخ ترميز فيديو قد لا تصلح لحاوية MP4، وبعض delegates الإضافية للصورة تعتمد على البناء المستخدم.

أدوات الصوت السبع تتشارك Input/Output وفق الأصل. عند تشغيل وظائف مختلفة على الاسم نفسه، انقل النتيجة السابقة خارج Output حتى لا تُتخطى. يوجد تحقق من العملية الأولى في الاختبارات، مع أرشفة كل نتيجة اختبار على حدة. لم يُغيّر اسم النتيجة أو مكانها تلقائيًا.

للنقل، انسخ الجذر كاملًا مع `System/Shared`، ومع `System/Bin` إذا جهزت توزيعات محلية كاملة والتزمت بشروط توزيعها. لا تنتقل برامج النظام المكتشفة من الجهاز الأول تلقائيًا. لا يلزم نسخ `tests` أو بياناته. شغّل START_HERE على الجهاز الجديد، ثم استخدم Input/Output الخاصين بالأداة. لا حاجة للإنترنت عند توفر الاعتمادات محليًا.
