التاريخ: 2026-10-18. الفرع: **codex-improvements**. الحالة عند البدء نظيفة، ونقطة الرجوع قبل التنظيم هي `ed2f937fb1ffb6cbcbb58d21c31903a654bc742c`. لم يُعدّل main ولم يحدث دمج أو إعادة كتابة للتاريخ.

بقي في الجذر README.md وSTART_HERE.bat وSTART_HERE.md وBUILD_DISTRIBUTION.bat وBUILD_DISTRIBUTION.md، مع ملفات Git المخفية وdist المحلي. ذاكرة التنزيل الاختيارية أصبحت System/Downloads، ولا تدخل التوزيع.

**العدد النهائي 55 أداة:** IMG: 14، VID: 17، AUD: 6، PDF: 5، UTI: 11، NET: 2. لكل BAT دليل MD مستقل، وبقيت مراجع MD الأصلية الخمسة عشر أيضًا. أدوات Video - Audio السبع ما زالت تشترك في مجلدها وفق التصميم الأصلي؛ بقي اسم Video  Compression بمسافتين.

## التغييرات والحفاظ على الملفات

- نُقلت المجلدات كاملة، دون إعادة تنفيذ محركات المعالجة أو تعديل القوائم. قورنت أجسام BAT الـ55 مع نقطة البداية: التغيير الوحيد فيها هو مسار التشغيل المشترك حيث يلزم.
- حُدّث اكتشاف الجذر من System/Shared، ومسارات جميع المشغلات وPS1 المحلية، وفهرس الأدوات والاعتمادات والاختبارات وروابط MD.
- أولوية الاعتمادات أصبحت System/Bin ثم البرامج المثبتة المتوافقة. بقي طلب موافقة كل تنزيل وفحص SHA-256 وإعادة الفحص، دون تعديل PATH العام أو Registry.
- بناء التوزيع يتضمن Tools وSystem وأدلة التشغيل والملفين START_HERE وBUILD_DISTRIBUTION وREADME وسجل بصمات الملفات. إنشاء نسخة جديدة من التوزيع نفسه ممكن أيضًا. نسخ البرامج المحلية خيار مستقل.
- جرى تتبع **633 ملفًا** من حالة البداية إلى موقعه الحالي، دون فقد ملف. تحققت بصمات Git غير المرشحة لـ**428 ملفًا محفوظًا وملف بيانات**، بينها أرشيف الأصل والعينات والسجلات المتتبعة. تفاصيل النقل في [migration-retention.json](migration-retention.json).
- حُفظت تقارير JSON السابقة بحالتها الأصلية في Development/tests/recorded/before-reorganization قبل تحديث نتائج التشغيل. النسخ التجريبية القديمة بقيت كما هي؛ مساراتها القديمة داخل السجلات واللقطات تاريخية وليست مسارات تشغيل المشروع الحالي.
- لا تدخل Development أو .git أو ذاكرة التنزيل أو السجلات أو بيانات Input/Output/Watermark في ZIP. المجلدات اللازمة موجودة فارغة، بما فيها Left/Right وWatermark.
