# مقارنة التصميم الأصلي والتنفيذ الحالي

تاريخ المراجعة: 2026-10-18. المرجع: `_original/original.zip` وملفات المصادر الحالية. بدأ العمل من أحدث `origin/main` عند commit `c02c4f3`، على فرع `codex-improvements` مستقل. كانت الحالة المحلية نظيفة عند الإنشاء.

## ما وجدته في النسخة الأصلية

الأرشيف يحتوي 21 BAT و 15 ملف MD وبنية المجلدات الأصلية. يعتمد الأسلوب على عنوان إنجليزي وفواصل نصية وقائمة مرقمة أو choice، ثم Input/Output بجانب BAT، واختيار الإعدادات قبل المعالجة، وملخص نجاح/فشل في النهاية. ملفات MD مراجع عربية مفصلة مع أقسام What does، Best Daily Command، Parameters، أوامر وأمثلة وملاحظات.

أدوات Video - Audio السبع تتشارك مجلدًا واحدًا و Input/Output في الأصل؛ بقي هذا الاستثناء حفاظًا على مساراتها وتجربة استخدامها. الأدوات الـ 25 المضافة في هذا الفرع لكل منها مجلد مستقل و BAT و PS1 و MD و Input/Output.

## تنظيم المعالجة وتبسيط الصيانة

الأدوات الجديدة تحمل أوامرها وقائمتها داخل PS1 محلي بجانب BAT. يختصر BAT بدء PowerShell المحلي مع تعطيل Delayed Expansion، وتبقى وظائف المسارات والتحقق وعدم استبدال النتائج واكتشاف البرامج مشتركة داخل Core.

المسارات المهمة للصيانة:

```text
أداة أصلية:    BAT بالقائمة الأصلية → ToolRunner → Core / Archives
الدفعة التسع: BAT → NewTool للواجهة والتحقق من البصمات → ToolRunner
أداة جديدة:   BAT → PS1 بجانبها → Core لوظائف I/O واكتشاف البرامج
التجهيز:      START_HERE → Setup → Download / Core / Archives
التوزيع:      BUILD_DISTRIBUTION → Build → Core / Archives
```

تبقى ToolRunner و NewTool للأدوات السابقة التي اجتازت اختباراتها؛ لم تُعد كتابتها دفعة واحدة. أزيلت الدالة Get-Media غير المستعملة بعد البحث عن جميع استدعاءاتها. لا تمر الأدوات الـ 25 الجديدة عبر هذين الملفين، ولا يحتاج تعديل وظيفة جديدة إلى تعديل موزع مركزي.

| الملف داخل _shared | سبب الاحتفاظ به |
|---|---|
| Core.ps1 | استدعاء البرامج دون shell، المسارات، Unicode، فحص الاعتمادات، نشر الملفات دون overwrite، تنظيف مساحة عمل محددة |
| ToolRunner.ps1 | معالجة الأدوات الثلاثين السابقة المستقرة |
| NewTool.ps1 | واجهة الدفعة التسع القديمة والتحقق من SHA-256 |
| Check.ps1 | نقطة الفحص التي تستدعيها BAT الأصلية |
| Validate.ps1 | رفض قيم القوائم المخصصة قبل إعادة تفسير CMD لها |
| Archives.ps1 | إنشاء ZIP وحفظ المجلدات الفارغة وفك ZIP الآمن؛ يُعاد استخدامه في التجهيز والتوزيع |
| Download.ps1 | تنزيل الحزم المثبتة والتحقق منها ونسخ شجرة برنامج مثبت بعد الموافقة |
| Setup.ps1 | حوار START_HERE والفحص وإعادة المحاولة |
| Build.ps1 | إنتاج توزيع نظيف جديد من قائمة ملفات واضحة |
| tools.json | سجل أسماء ومسارات واعتمادات 55 أداة للتجهيز والتوثيق والبناء |
| packages.json | بيانات ثلاث حزم تنزيل ثابتة وروابطها وبصماتها ورخصها |

لا توجد مكتبات PowerShell إضافية للتشغيل. البرامج الخارجية هي FFmpeg/FFprobe و ImageMagick و Ghostscript، ويستخدم باقي العمل Windows/.NET المدمج. القائمتان JSON بيانات وصفية؛ المعالجة الخاصة بالأداة موجودة في ملفاتها المذكورة أعلاه.

## الاختبارات والنسخة الاحتياطية

رفع كل الملفات سابقًا كان مطلوبًا للنسخ الاحتياطي. بقيت الملفات المتتبعة كما هي ولم يُحذف أي منها. تذهب الجولات المؤقتة الجديدة إلى tests/_work أو tests/_sandbox، ومخرجات البناء إلى dist؛ تجاهلها في Git لا يزيل الملفات المتتبعة سابقًا.

BUILD_DISTRIBUTION ينسخ BAT و PS1 و MD المطلوبة فقط، ويُنشئ مجلدات المدخلات والمخرجات فارغة، ويُنتج ZIP و manifest ببصمات SHA-256. يمكن تضمين توزيعات_bin المحلية الكاملة دون نسخ برامج من خارج المشروع تلقائيًا.
