# اختيار الإضافات

اختيرت الإضافات بحسب الفائدة اليومية والاعتمادات المتاحة وحفظ الأصول وانخفاض مخاطر التغيير. قائمة التنفيذ ليست هدفًا عدديًا.

| الوظيفة | الفائدة | التعقيد/المخاطر | القرار |
|---|---|---|---|
| SHA-256 وإنشاء/تحقق manifest | التحقق بعد النقل والنسخ | منخفض؛ قراءة فقط | نُفذت |
| كشف التكرارات بالبصمة | توفير مراجعة موثوقة قبل حذف يدوي | منخفض مع تقرير فقط | نُفذت بلا حذف |
| جرد الملفات CSV | رؤية الأحجام والامتدادات ومواعيد التعديل | منخفض | نُفذت |
| ZIP Backup | نسخ محتوى Portable | متوسط؛ مساحة التخزين | نُفذت دون حذف أو مزامنة تدميرية |
| ZIP Extract المعزول | فك أرشيفات يومية | متوسط؛ Zip Slip ومساحة التخزين | نُفذت مع رفض المسارات والروابط وحدود استخراج |
| Audio Converter | مجلد AUD فارغ؛ الأدوات القديمة تعالج صوت الفيديو فقط | منخفض؛ FFmpeg موجود أصلًا | نُفذت |
| Media Info | تشخيص توافق ملفات الوسائط | منخفض؛ FFprobe يأتي مع FFmpeg | نُفذت |
| Video Thumbnail | صورة مصغرة أو معاينة لفيديو | منخفض؛ FFmpeg نفسه | نُفذت |
| Merge PDF | وظيفة مكملة لضغط PDF | متوسط؛ الحفاظ على المدخلات وترتيب محدد | نُفذت باستخدام Ghostscript نفسه |
| تنظيف النظام/Registry أو إلغاء خدمات | أثر حساس وصعوبة التراجع | مرتفع | لم تُنفذ؛ لا تناسب هدف الأدوات الآمنة |
| حذف تكرارات أو إعادة تسمية جماعية تلقائية | قد تزيل/تغيّر بيانات المستخدم | متوسط/مرتفع | أولوية مؤجلة؛ تقرير التكرارات والجرد يغطيان الفحص الآمن |
| AI Background Removal / Super Resolution | يحتاج نماذج وتنزيلات وإدارة GPU وتراخيص إضافية | مرتفع ومواصفات غير محددة | لم تُنفذ؛ المذكور في الشروح مقارنة تقنية فقط |
| OCR/PDF تحرير متقدم | يحتاج اعتمادًا جديدًا وتحديدًا للغات/الدقة | متوسط/مرتفع | مؤجل لتجنب إدخال برامج غير ضرورية |
| فحوص شبكة وعمليات صيانة موسعة | مفيدة، لكن تتطلب تعريف الاتصال والخصوصية والتغييرات المرادة | متوسط | لم تُضف لمجرد زيادة عدد الأدوات |

لم تظهر ملفات BAT مبتورة أو TODO لتكملة أداة منفصلة؛ كانت الأدوات الأصلية مكتوبة وظيفيًا لكن بعض مسارات التشغيل غير موثوقة. اكتُمل نقص التشغيل والتجهيز والتحقق المشترك، وأضيفت وظائف إلى AUD وUTI دون الادعاء بوجود خطة أدوات قديمة غير موجودة.
