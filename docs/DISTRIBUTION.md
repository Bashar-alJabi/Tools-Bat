# نقل النسخة النظيفة إلى جهاز آخر

1. من نسخة التطوير شغّل BUILD_DISTRIBUTION.bat، واختر الأدوات فقط أو تضمين توزيعات _bin المحلية الكاملة.
2. ينتج مجلد و ZIP داخل dist؛ لا تُحذف الاختبارات أو النسخ الاحتياطية من المستودع.
3. انقل المجلد كاملًا أو فك ZIP على Windows 10/11 في مجلد قابل للكتابة.
4. شغّل START_HERE.bat. الاعتمادات المحلية لها الأولوية، ثم المثبتة، ثم تنزيلات اختيارية متحقق منها.
5. إن كانت الاعتمادات موجودة محليًا تعمل الأدوات دون إنترنت. التوزيع الخالي من البرامج يحتاج تجهيزًا عند الجهاز الآخر.
6. اقرأ MD الخاص بالأداة، وضع الملفات في Input واستلم النتائج من Output.

التوزيع يضم الأدوات وشرحها وملفات التشغيل المشتركة الضرورية و README وسجل الاعتمادات؛ لا يضم .git أو tests أو_original أو_downloads أوتقارير التطوير أو ملفات المستخدم في Input/Output/Watermark. مجلدات التشغيل تُنشأ فارغة داخل ZIP أيضًا.

ملف distribution-manifest.json يسجل SHA-256 لمحتوى كل ملف قبل كتابة manifest نفسه. لا يحفظ صلاحيات NTFS أوالملكية أو Alternate Data Streams، وليس صورة نظام. القابلية للنقل لا تمنح تلقائيًا حق إعادة توزيع برامج الطرف الثالث؛ راجع DEPENDENCIES.md.

البرامج المثبتة خارجيًا لا تُضم تلقائيًا. START_HERE.bat --portable يعرض نسخ شجرة البرامج المثبتة الكاملة إلى _bin بعد الموافقة لكل برنامج؛ بعدها يمكن إعادة البناء مع تضمينها. إذا تعذّر تحديد مجلد التوزيعة بأمان، يُحفظ الوضع السابق وتظهر إرشادات التجهيز اليدوي.
