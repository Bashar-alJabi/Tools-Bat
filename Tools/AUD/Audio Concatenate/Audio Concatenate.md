# 🛠️ Audio Concatenate — وصل المقاطع الصوتية

> وصل المقاطع واحدًا بعد الآخر حسب ترتيب أسمائها، مع توحيدها إلى Stereo 48 kHz WAV قبل الوصل.

## 🎯 What does Audio Concatenate do?

وصل المقاطع واحدًا بعد الآخر حسب ترتيب أسمائها، مع توحيدها إلى Stereo 48 kHz WAV قبل الوصل. هذه أداة مستقلة في الاستخدام: تفتح ملف BAT الموجود هنا، وتتعامل مع مجلدي Input و Output التابعين لها. ملف المعالجة `Audio Concatenate.ps1` بجانب BAT يوضح الأوامر الخاصة بهذه الوظيفة؛ وظائف الأمان واكتشاف البرامج فقط مشتركة في `../../System/Shared/Core.ps1`.

## 📦 المتطلبات والصيغ

- Windows 10/11 و Windows PowerShell 5.1 المدمج؛ لا تحتاج Administrator.
- الاعتماد: **FFmpeg 6 أو أحدث، مع FFprobe المرفق به**.
- الصيغ/المدخلات: MP3/WAV/M4A/AAC/FLAC/OGG/Opus/WMA.
- اكتشاف البرامج يبدأ بالنسخة المحلية في `System/Bin` ثم المثبتة. استخدم [START_HERE](<../../../START_HERE.md>) للتجهيز الاختياري؛ الأداة لا تنزل برامج وحدها.
- احتفظ بالمجلد داخل شجرة المشروع مع `System/Shared`. نسخ BAT منفردًا لا ينقل ملف المعالجة ووظائف المسارات.

## ⭐ أفضل طريقة للاستخدام اليومي

1. ضع الملفات التجريبية/المطلوبة في `Input` داخل **هذا** المجلد.
2. افتح `Audio Concatenate.bat` بالنقر المزدوج، أو من CMD.
3. اختر رقم العملية من القائمة. `Q` يغلق الأداة دون معالجة.
4. اقرأ ملخص النجاح/الإخفاق. الناتج داخل `Output`.
5. افحص الناتج قبل استعماله. إعادة التشغيل لا تستبدل نتيجة تحمل الاسم نفسه.

## ⚙️ خيارات القائمة والإعدادات

[1] وصل كل الملفات؛ [Q] خروج. استخدم 001 و 002 في الأسماء للترتيب.

إدخال رقم غير موجود يعرض خطأ ويتيح اختيارًا آخر. الأعداد المخصصة يجب أن تطابق المجال المعروض؛ الإدخال غير الصحيح ينهي العملية بكود 2 دون تغيير الأصل.

## 📁 Input / Output

```text
Audio Concatenate/
├─ Audio Concatenate.bat
├─ Audio Concatenate.ps1
├─ Audio Concatenate.md
├─ Input/
└─ Output/
```

Input مخصص للأصول، و Output للنسخ أو التقارير. ملف `.gitkeep` يحفظ المجلد الفارغ في Git وتتجاهله المعالجة. تُتجاوز الروابط و Junctions. المعالجة مباشرة دون مجلدات فرعية، إلا Folder Compare الذي يفحص شجرتي Left و Right.

## 📚 مثال عملي

```text
001.wav + 002.mp3 → joined.wav
```

من CMD داخل مجلد الأداة:

```bat
"Audio Concatenate.bat"
"Audio Concatenate.bat" --help
"Audio Concatenate.bat" --check
set "TB_NO_PAUSE=1"
"Audio Concatenate.bat" --defaults
```

`--defaults` يختار الإعداد الافتراضي المذكور أعلاه ويعالج الملفات، و`--check` يفحص المتطلبات فقط. تستطيع استدعاء BAT بمسار كامل من مجلد آخر، مع إحاطة المسار بعلامتي اقتباس. عند تمرير مسار يحوي `!` من CMD أب فعّل `DisableDelayedExpansion` أولًا.

## 🧠 كيف تتم المعالجة؟

فك كل مقطع إلى pcm_s16le ثم concat demuxer. تُشغّل البرامج مباشرة بواسطة ProcessStartInfo دون تمرير أسماء ملفات المصدر إلى أوامر CMD. الأوامر الفعلية موجودة في ملف PS1 المحلي لتسهيل فهمها وتعديلها.

الملفات الناتجة تُجهّز أولًا في مجلد عمل خاص داخل Output، ثم تُنقل إلى الاسم النهائي بعد نجاح العملية. لا تُكتب فوق نتيجة سابقة، ويُنظّف مجلد العمل الذي أنشأته الأداة فقط.

## 🚨 الأخطاء والمشاكل المتوقعة

| الرسالة/الحالة | المعنى والتصرف |
|---|---|
| Missing or incompatible | جهّز الاعتماد عبر START_HERE أو ضع توزيعة كاملة متوافقة في System/Bin |
| No supported input files | Input فارغ أو الامتدادات غير مدعومة؛ لا توجد معالجة |
| SKIPPED | الاسم النهائي موجود؛ انقل الناتج السابق أو غيّر اسم المدخل |
| FAILED | تعذر قراءة الملف أو تشغيل البرنامج/حفظ الناتج؛ راجع الرسالة والمساحة والصلاحيات |
| Path exceeds | انقل المشروع إلى مسار أقصر؛ لا تعدّل الأداة سياسة Windows للمسارات |
| Invalid selection/number | اختر رقمًا من القائمة أو عددًا ضمن المجال |

كود الخروج: `0` نجاح أو لا مدخلات أو تخطي؛ `1` فشل معالجة عنصر؛ `2` إعداد/مدخل غير صالح أو اعتماد غير متاح؛ `3` Windows PowerShell غير موجود. Ping Host يرجع 1 عند غياب كل الردود مع الاحتفاظ بالتقرير.

## ⚠️ القيود والملاحظات المهمة

حد 100 مقطع. تحتاج مساحة لملفات WAV الوسيطة والنهائية، وقد تتجاوز تقدير ثلاثة أمثال المدخل المضغوط. الوصل تسلسلي وليس مزجًا متزامنًا، ولا يضيف Crossfade.

الحد المحافظ لمسار ملف 240 محرفًا، ولمسار مجلد ناتج أساسي 200 محرفًا. الملفات العربية والمسافات والمحارف الخاصة تُمرر كقيم ملفات حقيقية؛ لا توجد مسارات شخصية ثابتة. المخرجات المجمعة تُتخطى بكاملها إذا كان اسمها موجودًا.

## 🛡️ الأصول والنتائج

لا حذف للأصول ولا إعادة تسمية لها ولا تغيير لإعدادات Windows. تحويل الوسائط قد يعيد الترميز ويغير الحجم والبيانات الوصفية؛ احتفظ دائمًا بالأصل. النسخة الناتجة وسيلة للعمل اليومي وليست بديلًا عن مراجعة الملفات المهمة.
