# 🛠️ Batch Rename — إعادة تسمية بأنماط ومعاينة

> بادئة أو لاحقة أو استبدال حرفي أو ترقيم؛ يعرض الأسماء ويكشف التصادمات، وينسخ افتراضيًا.

## 🎯 الوظيفة والاستخدامات العملية

بادئة أو لاحقة أو استبدال حرفي أو ترقيم؛ يعرض الأسماء ويكشف التصادمات، وينسخ افتراضيًا. report.txt يصبحcopy_report.txt؛ استبدالdraft بـfinal يختلف عن Rename Copies القديمة ذات الترقيم الثابت فقط.

## 📦 المتطلبات والصيغ المدعومة

Windows 10/11 وWindows PowerShell 5.1؛ دون Administrator أو مكتبات إضافية. الاعتماد: **Windows PowerShell 5.1 و.NET المدمجان فقط**. الملفات المباشرة فيInput، حتى10000ملف؛ الأسماء الجديدة يجب أن تصح علىWindows.
الاكتشاف من System/Bin ثم البرامج المثبتة المتوافقة. [START_HERE](../../../START_HERE.md) يفحص التجهيز؛ هذه الأداة لا تنزّل شيئًا.


## ⭐ الاستخدام خطوة بخطوة

1. افتح مجلد هذه الأداة، واحتفظ بموقعه داخل Tools/UTI مع System.
2. ضع ملفاتك في Input حسب الشرح أدناه؛ الترتيب بالأسماء، فاستعمل بادئات001 و002 عند الحاجة.
3. افتح Batch Rename.bat بالنقر المزدوج.
4. اختر رقمًا من القائمة؛ Q خروج. لا تُمرر المدخلات إلى CMD كأوامر.
5. اقرأ SUCCESS/FAILED/SKIPPED وافحص النتيجة داخل Output.

## ⚙️ خيارات القائمة والإعدادات

[1] نسخ ببادئةcopy_؛ [2] لاحقة_copy؛ [3] استبدال حرفي؛ [4] ترقيمitem_0001؛ [5] إعادة تسمية الأصول بعد اختيار النمط وتأكيدRENAME ORIGINALS مع نسخة احتياطية. الافتراضي1.
الإدخال غير الصحيح يُرفض برسالة؛ الأرقام العشرية تستخدم النقطة. --help يعرض المساعدة دون معالجة، و--check يفحص المتطلبات، و--defaults يستخدم الخيار الافتراضي دون أسئلة تغيير الإعدادات.


## 📁 Input وOutput والمجلدات الخاصة

Input بجانب BAT هو نطاق الإدخال؛ Output بجانبه للنتائج، وليس مجلد العمل الحالي. لا مجلدات إضافية مطلوبة.
Output/rename-plan/preview.csv وCopies في وضع النسخ، أوOriginals الاحتياطي وstatus.txt في وضع تعديل الأصول.
ملفات .gitkeep لا تُعالج. الروابط وJunctions المتفرعة تُتجاوز. خطة الأسماء والنسخة الاحتياطية تُحفظ قبل إعادة تسمية الأصول، وتُحتفظ بيانات الاسترجاع عند فشل حركة الملفات.


## 📚 مثال عملي

report.txt يصبحcopy_report.txt؛ استبدالdraft بـfinal يختلف عن Rename Copies القديمة ذات الترقيم الثابت فقط.
Output/rename-plan/preview.csv وCopies في وضع النسخ، أوOriginals الاحتياطي وstatus.txt في وضع تعديل الأصول.

```bat
"Batch Rename.bat" --help
"Batch Rename.bat" --check
set "TB_NO_PAUSE=1"
"Batch Rename.bat" --defaults
```

من مجلد آخر استخدم مسار BAT المحاط باقتباس. عند وجود % أو! في المسار، تجنّب CALL إضافيًا وأوقف Delayed Expansion في CMD الأب. النقر المزدوج لا يحتاج إعدادًا.

## 🚨 الأخطاء الشائعة وحلولها

- اعتماد مفقود أو غير متوافق: شغّل START_HERE أو جهّز توزيعة كاملة مرخصة في System/Bin.
- لا مدخلات مدعومة: أضف الصيغ المذكورة إلى Input؛ الخروج0 هنا يعني عدم وجود عمل.
- FAILED: اقرأ رسالة البرنامج؛ تحقق من سلامة الملف والعدد والأبعاد والترجمات أو المجلد الخاص عند الحاجة.
- SKIPPED: الاسم الناتج موجود؛ انقله أو أعد تسميته يدويًا إذا أردت معالجة جديدة. لا تُستبدل نتيجة قديمة.
- نقص مساحة/صلاحية أو مسار طويل: انقل المشروع لمسار أقصر قابل للكتابة، ووفر مساحة للملفات الوسيطة.

كود0 نجاح/لا عمل/تخطي، و1 فشل معالجة، و2 إعداد أو اعتماد غير صالح، و3 غياب Windows PowerShell. الأخطاء لا تعني نجاحًا لمجرد وجود مجلد Output.

## ⚠️ القيود وما لا تستطيع الأداة فعله

القائمة5 اختيار حساس وقت التشغيل، ولا تُنفذ بالافتراضي. ترفض أسماء محجوزة وتصادمات غير حساسة لحالة الأحرف. لا تعالج المجلدات ولا تغيّر الامتداد عمدًا؛ انقطاع الجهاز أثناء حركة الأصول قد يحتاج الرجوع إلىOriginals وpreview.csv.
الحد المحافظ لمسار الملف240 محرفًا، ولمجلد نتيجة مجمعة200 محرف. إعادة ترميز الوسائط قد تغيّر حجمها وبياناتها الوصفية. المعالجة الخاصة بهذه الأداة في PS1 المحلي، مع الاستفادة من وظائف الأمان الموجودة في Core.ps1 فقط.

## 🛡️ المحافظة على الملفات الأصلية

الوضع الافتراضي نسخ دون تغيير الأصول. الخيار5 وحده يغيّر أسماء الأصول بعد كتابة RENAME ORIGINALS، مع حفظ Originals وبصماتها وخطة preview.csv. لا تغييرات على إعدادات Windows. في وضع تعديل الأصول تُنقل الملفات على مرحلتين عبر مساحة خاصة داخل Input؛ عند فشل العملية تُحاول الاستعادة وتُحتفظ الملفات التي تعذر استرجاعها مع إرشاد مكانها. إعادة التشغيل تتخطى الاسم الموجود، ولو اخترت إعدادًا مختلفًا؛ انقل النتيجة السابقة أولًا عند الرغبة بإعادة المعالجة.
