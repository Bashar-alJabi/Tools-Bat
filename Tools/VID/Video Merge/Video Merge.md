# 🛠️ Video Merge — دمج مقاطع الفيديو بالترتيب

> دمج تلقائي مباشر عند تطابق خصائص المسارات، وإلا توحيد H.264/AAC مع إطارات مناسبة؛ ليس مزج الصوت في فيديو.

## 🎯 الوظيفة والاستخدامات العملية

دمج تلقائي مباشر عند تطابق خصائص المسارات، وإلا توحيد H.264/AAC مع إطارات مناسبة؛ ليس مزج الصوت في فيديو. 001.mp4 و002.mp4 ينتجان مقطعًا متتابعًا؛ يطبع المسار المختار.

## 📦 المتطلبات والصيغ المدعومة

Windows 10/11 وWindows PowerShell 5.1؛ دون Administrator أو مكتبات إضافية. الاعتماد: **FFmpeg 6+ وFFprobe**. MP4/MKV/MOV/AVI/M4V/WebM؛ حسب توفر مفكك الترميز في FFmpeg.
الاكتشاف من System/Bin ثم البرامج المثبتة المتوافقة. [START_HERE](../../../START_HERE.md) يفحص التجهيز؛ هذه الأداة لا تنزّل شيئًا.


## ⭐ الاستخدام خطوة بخطوة

1. افتح مجلد هذه الأداة، واحتفظ بموقعه داخل Tools/VID مع System.
2. ضع ملفاتك في Input حسب الشرح أدناه؛ الترتيب بالأسماء، فاستعمل بادئات001 و002 عند الحاجة.
3. افتح Video Merge.bat بالنقر المزدوج.
4. اختر رقمًا من القائمة؛ Q خروج. لا تُمرر المدخلات إلى CMD كأوامر.
5. اقرأ SUCCESS/FAILED/SKIPPED وافحص النتيجة داخل Output.

## ⚙️ خيارات القائمة والإعدادات

[1] تلقائي؛ [2] توحيد دائم 1280×720 و30FPS وصوت48k stereo؛ [3] نسخ مسارات متطابقة فقط. الافتراضي1.
الإدخال غير الصحيح يُرفض برسالة؛ الأرقام العشرية تستخدم النقطة. --help يعرض المساعدة دون معالجة، و--check يفحص المتطلبات، و--defaults يستخدم الخيار الافتراضي دون أسئلة تغيير الإعدادات.


## 📁 Input وOutput والمجلدات الخاصة

Input بجانب BAT هو نطاق الإدخال؛ Output بجانبه للنتائج، وليس مجلد العمل الحالي. لا مجلدات إضافية مطلوبة.
Output/merged.mp4.
ملفات .gitkeep لا تُعالج. الروابط وJunctions المتفرعة تُتجاوز. نتائج المجموعة تُنشر معًا بعد نجاح العملية، ولا تُكتب تقارير جزئية عند فشل عنصر.


## 📚 مثال عملي

001.mp4 و002.mp4 ينتجان مقطعًا متتابعًا؛ يطبع المسار المختار.
Output/merged.mp4.

```bat
"Video Merge.bat" --help
"Video Merge.bat" --check
set "TB_NO_PAUSE=1"
"Video Merge.bat" --defaults
```

من مجلد آخر استخدم مسار BAT المحاط باقتباس. عند وجود % أو! في المسار، تجنّب CALL إضافيًا وأوقف Delayed Expansion في CMD الأب. النقر المزدوج لا يحتاج إعدادًا.

## 🚨 الأخطاء الشائعة وحلولها

- اعتماد مفقود أو غير متوافق: شغّل START_HERE أو جهّز توزيعة كاملة مرخصة في System/Bin.
- لا مدخلات مدعومة: أضف الصيغ المذكورة إلى Input؛ الخروج0 هنا يعني عدم وجود عمل.
- FAILED: اقرأ رسالة البرنامج؛ تحقق من سلامة الملف والعدد والأبعاد والترجمات أو المجلد الخاص عند الحاجة.
- SKIPPED: الاسم الناتج موجود؛ انقله أو أعد تسميته يدويًا إذا أردت معالجة جديدة. لا تُستبدل نتيجة قديمة.
- نقص مساحة/صلاحية أو مسار طويل: انقل المشروع لمسار أقصر قابل للكتابة، ووفر مساحة للملفات الوسيطة.

كود0 نجاح/لا عمل/تخطي، و1 فشل معالجة، و2 إعداد أو اعتماد غير صالح، و3 غياب Windows PowerShell. الأخطاء لا تعني نجاحًا لمجرد وجود مجلد Output.

## ⚠️ القيود وما لا تستطيع الأداة فعله

مقطعان إلى50؛ يأخذ أول فيديو وأول صوت فقط، ولا ينقل الترجمات والفصول. التوحيد يعيد الترميز وقد يغيّر الجودة؛ عدم تطابق أي خصائص يمنع النسخ المباشر.
الحد المحافظ لمسار الملف240 محرفًا، ولمجلد نتيجة مجمعة200 محرف. إعادة ترميز الوسائط قد تغيّر حجمها وبياناتها الوصفية. المعالجة الخاصة بهذه الأداة في PS1 المحلي، مع الاستفادة من وظائف الأمان الموجودة في Core.ps1 فقط.

## 🛡️ المحافظة على الملفات الأصلية

لا حذف أو تعديل للأصول أو إعدادات Windows. تُنسخ المدخلات إلى مساحة عمل خاصة عند المعالجة، ثم تُنشر النتيجة إلى اسم جديد دون overwrite. إعادة التشغيل تتخطى الاسم الموجود، ولو اخترت إعدادًا مختلفًا؛ انقل النتيجة السابقة أولًا عند الرغبة بإعادة المعالجة.
